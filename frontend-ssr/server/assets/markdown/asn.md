## ASN 是什么

ASN（Autonomous System Number，自治系统号）是互联网中每个自治系统的唯一编号。运营商、云厂商、大型企业把自己的 IP 地址段通过 BGP 宣告出去，这些地址段就归属到对应的 AS。查 ASN 回答的是「这段 IP 由哪个网络运营」，而不是「使用者在哪个城市」。

## 结果字段怎么读

| 字段 | 含义 |
| --- | --- |
| AS 号 | 形如 `AS4134` 的自治系统编号，可据此查该网络的路由策略 |
| AS 名称 | 运营该地址段的机构，通常是运营商、云厂商或企业 |
| 注册机构 / 国家 | IP 段的注册归属，不等于实际访问地 |
| abuse 邮箱 / 电话 | 该网络的滥用投诉入口，处理扫描、攻击溯源时会用到 |

本站数据来自 MaxMind GeoLite2 与 DB-IP，部分节点会再用 WHOIS 补充 ASN 详情，因此不同节点看到的字段完整度可能不同。

## 几个常见误读

- **ASN 归属 ≠ 访问者位置**：手机流量常显示运营商省级出口；云主机显示的是云厂商的 AS。
- **CDN 后的源站查不到**：用户访问的是 CDN 边缘 IP，ASN 属于 CDN 厂商，不代表源站托管方。
- **同一域名多个 IP 归属不同**：双栈或分线路解析时，IPv4 与 IPv6 可能落在完全不同的 AS。
