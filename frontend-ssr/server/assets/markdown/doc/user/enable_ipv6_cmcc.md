# <span style="background-color: #00b050;color: white;font-size: 0.43em;border-radius: 5px;padding: 2px 5px;">原创</span> 移动宽带如何开启 IPv6（中国移动）

## 前言

本文主要介绍两种开启方法：

1. 从光猫 DHCP 获取 —— 光猫继续拨号，路由器只负责把 IPv6 传下去；
2. 路由器手动拨号获取 —— 光猫改桥接，路由器 PPPoE 拨号并申请 IPv6 前缀。

若您开启 IPv6 的目的是获取公网入站，请看第二节的桥接方案：部分 CMCC 光猫无法关闭 IPv6 入站防火墙，光猫拨号模式下入站流量会被拦在光猫上，路由器里怎么放行都没用。

先给个结论：**移动宽带能不能用 IPv6，取决于「光猫有没有把 IPv6 打开」和「路由器有没有把 IPv6 传下去」，跟套餐档位关系不大。** 下面的步骤全部围绕这两处配置展开。

## 0. 开之前先确认：你家移动宽带现在有没有 IPv6

别急着改桥接。移动很多地区的光猫出厂就已经开了 IPv6，先花一分钟确认，能少走一整轮弯路。

打开 [IP 查询](/ip-query)，看 IPv6 那一行：

| 页面显示 | 含义 | 下一步 |
|---|---|---|
| IPv6 行有 `2409:` 开头的地址 | 光猫已经把 IPv6 下发到内网 | 跳过第 1 节，直接看第 2 节调路由器 |
| IPv6 行空着，提示「没有 IPv6 地址」 | 内网完全没有 IPv6 | 去光猫后台看 IPv6 开关，见 3.1 |
| 只有 `fe80::` 开头的地址 | 链路本地地址，等于没通 | 同上，通常是光猫没下发前缀 |

> `2409::/16` 是中国移动的 IPv6 地址段（电信是 `240e::/16`，联通是 `2408::/16`），看到 `2409:` 基本可以确认用的是移动线路的 IPv6。

只想确认「当前网络是 IPv6 还是 IPv4 访问优先」，看 [IPv6 检测](/ipv6check)；想确认某个网站支不支持 IPv6，用 [IPv6 网站检测](/ipv6webcheck)。

## 1. 两种方案怎么选

| | 方案一：光猫拨号 + 路由器获取 | 方案二：光猫桥接 + 路由器拨号 |
|---|---|---|
| 要改哪里 | 只动路由器 | 光猫和路由器都要改 |
| IPv4 双 NAT | 有，两层 | 没有 |
| 路由器能拿到的前缀 | 通常一个 /64，不能再往下分 | 可申请 /56 或 /60，能分给多个网段 |
| 外网入站 | 基本不行，光猫防火墙会拦 | 可以做，在路由器上放行端口 |
| 风险 | 低，改坏了重启路由器就恢复 | 中，改错会全家断网，需要记住原配置 |
| 适合谁 | 只是想让设备用上 IPv6 | 有 NAS、远程访问、多网段需求 |

没有特殊需求就选方案一，改动最小。方案二值不值得折腾，取决于你是否需要外网访问家里的设备。

## 2. 方案一：光猫继续拨号，路由器开启 IPv6

### 2.1 先确认光猫侧的 IPv6 是开的

光猫管理地址一般是 `http://192.168.1.1`（少数型号是 `192.168.100.1` 或 `192.168.0.1`，以机身贴纸为准）。普通用户账号密码就印在贴纸上，格式通常是 `user` / 一串随机字符，不需要超级管理员账号。

登进去之后找这两个地方：

- **网络 → 宽带设置**：选中 `INTERNET` 那条连接，确认 **IP 模式** 是 `IPv4&IPv6`，不是只有 `IPv4`；
- **状态 → 网络侧信息**：看 IPv6 是否 `Connected`，以及有没有拿到前缀（`2409:` 开头的一串）。

如果 IP 模式只有 `IPv4`，改成 `IPv4&IPv6` 保存，等 10 秒左右生效，再回 [IP 查询](/ip-query) 看内网是否已经拿到地址。

### 2.2 路由器这一侧怎么填

不同品牌叫法不一样，但本质只有三种，按你家的拓扑选：

| 路由器里的叫法 | 什么时候选它 | 说明 |
|---|---|---|
| DHCPv6 客户端 / 动态 IP / 自动获取 | 路由器直接接光猫 LAN 口，且光猫给的是可再分的 IPv6 地址 | 路由器向上要地址，再给内网设备发 |
| IPv6 桥接 / Passthrough / 中继 / 穿透 | 光猫只给了一个 /64，路由器没法再切子网 | 把光猫的 IPv6 原样透传，内网设备直接从光猫要地址 |
| 静态 IP / 固定地址 | 上面的都拿不到地址 | 家用不推荐，除非你清楚当地前缀 |

最常见的坑：路由器选了 DHCPv6，但光猫只下发一个 /64，路由器自己拿到了地址、下面的电脑手机却没有 —— 这时改成 **Passthrough / IPv6 桥接** 就好了。

### 2.3 方案一的边界

在这个结构下，光猫是 IPv6 的「边界」，它的防火墙规则你多半改不动。表现就是：家里设备有公网 IPv6、能正常访问外网，但从外面连不进来。如果不是为了外网访问，这个状态完全够用，没必要改桥接。

## 3. 方案二：光猫改桥接，路由器 PPPoE 拨号

> 动手前先说清楚风险：改桥接会中断全屋上网，配错就得靠记忆恢复。请用手机流量打开着本文一步步做，并先把 3.2 的三样信息记下来。

### 3.1 登录光猫（需要超级管理员）

移动光猫的超级管理员账号是**另一套**，和机身贴纸上的 `user` 账号不是一回事。多数华为、中兴、吉比特、烽火代工机型的出厂默认是：

| 代工方 | 常见型号 | 用户名 | 默认密码 |
|---|---|---|---|
| 华为 | HG8546M / HS8545M / HG6145F | `CMCCAdmin` | `aDm8H%MdA` |
| 中兴 | F663N / F7607P | `CMCCAdmin` | `aDm8H%MdA` |
| 吉比特 | GM620 / H3-2S / H2-3 | `CMCCAdmin` | `aDm8H%MdA` |
| 烽火 | HG6821M | `CMCCAdmin` | `aDm8H%MdA` |

两点提醒：

- 部分地区装维在开通时改过超管密码，`CMCCAdmin` 登不上属于正常。这种情况直接打 10086 转宽带装维，说要「把光猫改成桥接、需要超管密码」，师傅远程就能改或给密码。
- **别恢复出厂设置**。移动光猫一旦恢复出厂，PPPoE 账号密码、IPTV 的 VLAN 绑定、语音配置全都没了，需要装维上门重新注册。

### 3.2 改之前先记下三样东西

1. **宽带账号和密码**：移动的账号一般是手机号，或 `手机号@139.gd` 这种带地域后缀的形式，密码多为业务密码或手机号后六位。不记得就去掌上营业厅查，或问装维。路由器拨号要用它，填错就是「已连接但无法上网」。
2. **INTERNET 连接的 VLAN ID**：光猫后台「网络 → 宽带设置」里那条 `INTERNET` 连接，名字类似 `2_INTERNET_R_VID_41`，`VID_` 后面那个数字就是 VLAN。大部分家用路由器不需要填（用的是 untagged），但个别地区要，记下来备用。
3. **IPTV 绑在哪个 LAN 口**：机顶盒那条线原本插在哪个口，改完要插回原口。IPTV 走的是另一条 VLAN，桥接只改 `INTERNET` 那条，别的连接不要动。

### 3.3 把 INTERNET 连接改成桥接

路径大致是 **网络 → 宽带设置**，选中 `INTERNET` 那条，按下面改：

| 项目 | 改成 |
|---|---|
| 连接模式 | `Bridge` / `桥接` |
| IP 模式 | `IPv4&IPv6`（部分机型桥接后这一项会隐藏，不影响） |
| VLAN / 802.1p | 保持原值不动 |
| DHCP 服务 | 保持开启，内网还有别的设备要靠它拿 IPv4 |

保存后光猫可能会自己重启拨号进程，大约 10 秒。此时家里会断网，属于正常 —— 拨号权已经交给路由器了。

### 3.4 路由器 PPPoE 拨号并开启 IPv6

登录路由器后台（地址在机身贴纸），在上网设置里按这个表填：

| 设置项 | 取值 | 说明 |
|---|---|---|
| 上网方式 | PPPoE / 宽带拨号 | 账号密码填 3.2 记的那组 |
| IPv6 开关 | 开启 | 部分路由器叫「IPv6 网络」或「IPv6 功能」 |
| IPv6 连接类型 | `Native` / `DHCPv6` | 桥接拨号必须选这个；只有光猫还在拨号时才选 Passthrough |
| 获取 IPv6 前缀 | 开启 DHCPv6-PD | **这一项不开，路由器自己有 v6、下面设备没有** |
| LAN 侧分配方式 | `SLAAC` + `DHCPv6` | SLAAC 给设备发地址，DHCPv6 发 DNS |
| MTU | `1492`，异常时降到 `1480` | PPPoE 头占 8 字节；大包不通多半是 MTU 问题 |

保存后看路由器的「上网信息」或「WAN 状态」：能看到一个 `2409:` 开头的 WAN IPv6 地址、以及一条前缀（形如 `2409:xxxx:xxxx:xx00::/56`），说明拨号和前缀委派都成功了。

### 3.5 DNS 与 MTU 的两个补充

- **DNS 优先用运营商自动下发的**。要手动填，可以用公共 IPv6 DNS：`2400:3200::1`（阿里）、`2402:4e00::`（腾讯）、`240c::6666`（下一代互联网）。移动自己的 IPv6 DNS 各地不同，填错反而解析慢。
- **「IPv6 能 ping 通但网页打不开」几乎都是 MTU 或 ICMPv6 被拦**。IPv6 不做分片，路径 MTU 发现依赖 ICMPv6 的「数据包过大」（类型 2）。在路由器防火墙里放行 ICMPv6 类型 1、2、3、4，再把 MTU 降到 `1480` 试一次。

## 4. 开完怎么验证

改完别只看「有地址」就结束，按这张表逐项过一遍：

| 想确认什么 | 用哪个工具 | 看到什么算成功 |
|---|---|---|
| 有没有拿到公网 IPv6 | [IP 查询](/ip-query) | IPv6 行出现 `2409:` 开头的地址 |
| 当前是 IPv6 还是 IPv4 优先 | [IPv6 检测](/ipv6check) | 提示「网络 IPv6 访问优先」 |
| 常访问的网站支不支持 IPv6 | [IPv6 网站检测](/ipv6webcheck) | AAAA 记录存在且能连通 |
| 本机 IPv6 能不能被外网连上 | [在线 TCPing](/ipv6tcping) | 从外部节点 ping 通你的 v6 地址 |
| IPv6 的实际速度 | [IPv6 测速](/ipv6speedtest) | 下载 / 上传跑满带宽 |
| 出口地址归属地对不对 | [IP 归属地查询](/location) | 定位到你的城市 |

命令行也可以直接看，适合排查「浏览器没走 IPv6」这类问题：

```sh
# Windows
ipconfig /all | findstr /i "IPv6"
ping -6 nipw.cn

# macOS / Linux
ifconfig | grep inet6
ping6 nipw.cn
```

`ping -6` 能通、`ping` 却不走 v6，说明系统的 IPv6 优先级被改过（Windows 可用 `netsh interface ipv6 show prefixpolicies` 查看）。

## 5. 常见问题

### 5.1 有 2409 地址，但网站还是走 IPv4

地址有了不代表流量会优先走 IPv6。先看 [IPv6 检测](/ipv6check) 的结论，再看系统是否被优化软件关掉了 IPv6，或者浏览器走了代理 / VPN（代理通常只转发 IPv4）。路由器里如果开了严格的「IPv6 防火墙」，也可能让部分站点回退。

### 5.2 只有 fe80:: 开头的地址

`fe80::` 是链路本地地址，任何开了 IPv6 协议的网卡都会有，它不代表你能上 IPv6 互联网。缺的是全局地址，原因通常是：光猫没下发前缀、路由器的 DHCPv6-PD 没开、或者路由器在二级 NAT 下选了 DHCPv6 而不是 Passthrough。

### 5.3 IPv6 打不开网页 / 部分网站加载一半

按顺序排查三件事：DNS 有没有下发 IPv6 地址、MTU 是不是设得过大、ICMPv6 有没有被防火墙全部拦掉。三者都正常还不行，就临时关掉路由器的 IPv6 防火墙，确认是不是规则问题。

### 5.4 IPv6 网速比 IPv4 慢

移动的 IPv6 出口和 IPv4 不是同一条链路，绕路是常见现象。用 [IPv6 测速](/ipv6speedtest) 和 [IPv4 测速](/speedtest) 各跑一次对比，差距在 10% 以内属于正常；如果明显慢，把路由器的 IPv6 关掉只留 IPv4 更实用。

### 5.5 想从外网访问家里的 NAS / 摄像头

这条路只有方案二走得通，而且要求：光猫桥接、路由器拿到公网 IPv6 前缀、路由器防火墙放行对应端口、设备本身有稳定的 IPv6 地址。注意 IPv6 没有 NAT，等于每台设备都直接暴露在公网上，**放行之前先确认设备的登录密码不是默认值**。地址会随前缀变化，需要 DDNS 配合。

### 5.6 改完 IPTV 不能看了

大概率是把 `IPTV` 那条连接也改成了桥接，或者机顶盒插错了 LAN 口。回到光猫后台，把 IPTV 连接恢复成原来的模式（一般是 Route + 绑定固定 LAN 口），机顶盒插回原口即可。

### 5.7 想改回去

光猫后台把 `INTERNET` 连接的**连接模式**从 `Bridge` 改回 `Route` / `PPPoE`，填回 3.2 记的宽带账号密码，保存。路由器那头改回「自动获取 IP」即可。移动光猫的拨号配置一般不会因为改桥接被删掉，但账号密码要自己确认一遍。
