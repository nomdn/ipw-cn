## 它是怎么工作的

输入任意公开网址，本站调用截图服务以 1280px 宽度渲染目标页面并生成截图，结果直接在页面中预览，无需安装浏览器插件或远程桌面。

截图服务采用双通道：主通道失败时自动降级到备用服务重新生成。备用服务是异步的，首次请求可能只返回占位图，此时页面会提示「正在生成截图中，请稍后」，稍后重试即可拿到实际截图。

## 能用来做什么

- **页面走查**：确认首屏布局、字体、图片与样式是否按预期渲染，快速发现资源加载失败或混合内容导致的空白。
- **上线校验**：改动发布后立刻截图，确认缓存是否刷新、新版本是否已生效。
- **内容存档**：为页面留一份当时呈现的快照，便于前后对比。
- **远程核验**：不用登录目标服务器，就能看到外部访问者实际看到的样子。

## 截图失败或不是预期页面

| 现象 | 常见原因 |
| --- | --- |
| 提示「截图加载失败」 | 目标站点不可达、屏蔽截图服务、需要登录，或渲染超时 |
| 显示的是占位图 | 备用服务仍在异步生成，等待后重新查询 |
| 截图落在验证页或 Cookie 提示页 | 目标站点有反爬或跳转，不代表源站异常 |
| 页面样式缺失或空白 | 目标站点资源加载失败、混合内容被浏览器拦截 |

目标站点证书无效时截图服务可能无法完成渲染，这类问题更适合用 SSL 证书检测工具排查；判断站点是否支持 IPv6 访问，则应用 IPv6 网站检测工具而非截图。
