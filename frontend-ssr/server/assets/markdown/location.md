## 为什么同一个 IP 会有不同答案

本站不做单一裁决，而是把多个 IP 地理位置库与 ASN 库的结果并列返回。差异通常来自三类原因：

- **入库时间不同**：IP 段重新分配后，各库更新可能相差数周到数月。
- **粒度不同**：有的给到城市，有的只到国家或省级；云厂商、专线 IP 常被标成注册地而非实际使用地。
- **回答的问题不同**：「这段 IP 归谁」（ASN）和「访问者在哪」（地理定位）本来就不是同一件事。

多家结果打架时，优先采信一致的部分（通常是国家/地区），城市与经纬度只作参考，不适合做风控判定。

## IPv6 地址查询和 IPv4 查询的结果差异

IPv4 查询与 IPv6 地址查询走的是同一套接口，但结果精度不完全一样。IPv4 地址段分配历史悠久、地理库覆盖较全，通常能定位到城市；IPv6 前缀按运营商大块下发，很多库只能给到国家或省级，跨地区复用同一前缀的情况也更常见。因此 IPv6 地址查询出现「国家正确、城市偏差」并不代表查询失败，多库并列时以一致的部分为准。

本页既支持直接输入地址查询，也可以从首页的出口地址一键跳转过来，结果里会同时给出地理库与 ASN 的对照。

## 字段怎么读

| 字段 | 含义 | 注意 |
| --- | --- | --- |
| 国家 / 省份 / 城市 | 地理库给出的位置 | 精度有限，不代表设备所在地 |
| ASN / AS 名称 | IP 段所属自治系统 | 指向运营商或云厂商，不是使用者 |
| ISP | 接入运营商 | 移动网络、CDN 出口常与预期不同 |
| 经纬度 | 库内置近似坐标 | 一般是城市中心点 |

## IPv4 与 IPv6 的差异

IPv6 地址段分配粒度更粗、回收更频繁，各库覆盖度差异比 IPv4 明显。若结果为空或只剩 ASN 信息，通常是该段尚未被地理库收录。

页面内置的 curl 示例可直接取回当前出口 IP，用于核对查询对象是不是你以为的那个地址。
