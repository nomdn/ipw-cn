本页是在线 IP 查询入口：打开即显示当前网络的公网 IPv4 地址、IPv6 地址与网络优先级，不用输入任何内容，也无需注册。下面说明每一项结果的含义，以及 IPv4 查询、IPv6 查询分别能查到什么。

## IP 查询能查到什么：IPv4 与 IPv6 出口地址

首页展示的不是本机网卡地址，而是**当前网络访问公网时使用的出口 IP**。页面分别向三个独立接口发起探测：纯 IPv4 地址、纯 IPv6 地址，以及一个 IPv4/IPv6 双栈域名。三条结果各自独立返回、谁先到谁先显示，因此某一条慢或超时不会拖住另外两条。

- **IPv4 行**：当前网络的 IPv4 公网出口地址。后面的「查询归属地」会带着这个地址跳转到 [IP 归属地查询](/location)。
- **IPv6 行**：当前网络的 IPv6 公网出口地址。若显示「没有IPv6地址」，说明这次探测没有走通 IPv6 链路。
- **网络优先级**：由双栈域名的返回结果判定。返回 IPv6 地址即「您的网络IPv6优先」，返回 IPv4 地址则是「IPv4优先」。它反映的是系统实际选择的协议栈，而不是「有没有 IPv6 地址」——两者可能不一致。

页面下方的 curl 示例用的就是同一组接口，可以直接在终端复现结果。

## IPv6 查询和 IPv4 查询有什么区别

IPv4 查询返回的是运营商分配的 32 位公网地址，形如 `1.2.3.4`；IPv6 查询返回的是 128 位地址，形如 `2408:8207:78cc::1`。两者互不替代：同一条网络可能只有 IPv4、只有 IPv6，或者两者都有。把查到的地址填进 [IP 归属地查询](/location)，还能继续看它属于哪个运营商、哪个地区，这一步就是常说的 IPv6 地址查询。

只关心「我有没有 IPv6」时，看本页的 IPv6 行即可；需要知道某个**域名**有没有 IPv6 地址，用 [DNS 查询](/dns) 查 AAAA 记录，或直接用 [网站 IPv6 检测](/ipv6webcheck)。

## 怎么判断本机是否支持 IPv6

| 页面显示 | 说明 |
| --- | --- |
| IPv6 行有地址、且提示 IPv6 优先 | 已获得 IPv6 地址，系统默认优先走 IPv6 |
| IPv6 行有地址、但提示 IPv4 优先 | 链路支持 IPv6，只是系统的前缀策略偏向 IPv4 |
| IPv6 行为空、显示「没有IPv6地址」 | 运营商未下发地址，或光猫、路由器、系统未开启 IPv6 |

第一种是最常见的正常状态。第二种不代表配置错误，调整方式见 [Windows 设置 IPv4/IPv6 访问优先级](/doc/user/ipv4_ipv6_prefix_precedence)。第三种需要从宽带侧排查，见 [个人宽带如何开启 IPv6](/doc/user/enable_ipv6)。手机蜂窝网络通常默认已开启 IPv6，不需要额外设置。

## IP 查询地址：为什么出口地址不等于本机地址

家庭宽带和手机网络普遍经过 NAT 或运营商级 CGNAT，网卡上看到的 `192.168.x.x`、`10.x.x.x` 或 `fe80::` 是内网地址，只有本页返回的公网出口地址才是外部网站看到的那一个。使用代理、VPN 或公司出口时，显示的是代理或出口网关的地址；开启 IPv6 隐私扩展的系统还会定期更换临时地址，前后两次查询结果不同属于正常现象。

这直接影响结果解读：出口 IP 的归属地通常是运营商机房或代理节点所在城市，未必是设备实际所在地；多个地理库给出的结果也可能不一致，原因见 [IP 归属地查询](/location) 的说明。

## 本机检测和网站检测是两回事

本机检测回答「我这条网络能不能用 IPv6」，取决于运营商、路由器和操作系统；[网站 IPv6 检测](/ipv6webcheck) 回答「某个域名能不能被 IPv6 用户访问」，取决于站长的 AAAA 记录、服务监听和防火墙。一侧通过不代表另一侧通过。不确定该查哪一个时，先看 [IPv6 检测方法与工具](/ipv6check)，那一页按场景列出了对应工具。
